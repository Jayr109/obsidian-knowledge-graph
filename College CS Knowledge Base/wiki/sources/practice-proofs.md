# Practice — Proofs

**Source file:** `raw/CSCE_411_Proofs_Practice_Solutions (2).pdf`

**Topics:** Mathematical induction, proof techniques, algorithm correctness

## Content Overview

This practice set covers the core proof techniques used throughout CSCE 411:

- **Mathematical induction:** weak induction, strong induction, structural induction
- **Proof by contradiction:** assuming the negation and deriving a logical impossibility
- **Proof by contrapositive:** proving ¬B ⇒ ¬A as equivalent to A ⇒ B
- **Algorithm correctness proofs:** loop invariants, well-foundedness of recursion, termination arguments

These techniques appear throughout the course — in asymptotic analysis proofs, graph algorithm correctness arguments, and decidability/undecidability proofs.
