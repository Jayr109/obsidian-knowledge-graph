The Price-to-Earnings (PE) ratio is a stock valuation multiple equal to the market price per share divided by earnings per share. While widely used for quick comparables analysis, the instructor strongly cautions it should only provide a rough ballpark estimate — never a rigorous valuation.

## Definition

```
PE Ratio = Stock Price / Earnings Per Share
```

## The PE Valuation Model

To estimate a company's value using PE:
1. Find comparable publicly traded companies in the same industry.
2. Calculate each company's PE ratio.
3. Take the average (or median).
4. Multiply by the target company's EPS.

```
Estimated Value = Average Comparable PE × Target EPS
```

## Why PE Ratios Are a Weak Tool

The fundamental value of any financial instrument is a function of:
1. Expected future cash flows
2. Timing of those cash flows
3. Riskiness of those cash flows

PE ratios measure none of these directly. Earnings give a rough proxy for future cash flows but vary based on accounting choices, growth stage, capital structure, and dozens of other factors. As a result, PE ratios vary enormously even within the same industry.

**Example from lecture — hotel chains:**
Hilton (~36), Marriott (~24), Choice Hotels (~20), Hyatt (~79). If you wanted to value a new hotel company, which comparable would you choose?

## Correct Alternative

For rigorous valuation, use discounted cash flow analysis:
- Forecast [[Free Cash Flow]] projections
- Discount at appropriate rate (WACC)
- Apply [[Net Present Value]] framework
